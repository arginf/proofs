# arginf/proofs

The source of truth for [arginf.com](https://arginf.com): Lean 4 statements and proofs, built on cslib-frontier, CSLib and Mathlib. Every statement lives in its own folder, named by the hash of the statement.

```
Theorems/<hash>/
  Statement.lean                      def statement : Prop := ...
  attempts/<attempt>/Attempt.lean     a line of proof; complete (no sorry) = a proof
  attempts/<attempt>/attempt.toml     parent = "<attempt hash>" or ""
curation.toml                         featured and example statements (maintainers only)
models.toml                           allowlisted open-weights model + runtime for English readings
```

- **The statements are the statements.** Theorem folders contain plain Lean only: no prose, no comments, no string literals, and nothing that runs code while Lean compiles it (see `tools/safety.py`). The site shows the Lean.
- **Verified = at least one merged complete attempt.** Every attempt without `sorry` is a proof. CI re-checks every declaration in the kernel (`leanchecker`) and checks that it proves exactly `statement`, using only `propext`, `Classical.choice` and `Quot.sound` (no `sorry`, no custom axioms, no `native_decide`). A statement can have any number of proofs. The site marks the first accepted 💡, the shortest 🎯 and the most 👍 on its PR, and credits each to the GitHub login that merged it.
- **Attempts are checkpoints.** Each line of proof has its own hash, which covers its code and its parent. Partial attempts merge, and anyone can continue any of them.
- **Lemmas are statements too.** Build on a proved result by importing one of its proofs: `import Theorems.«<hash>».attempts.«<attempt>».Attempt`.
- **Popularity = attempts.** The site ranks statements by how many lines of proof they attract.
- **English readings** are generated by CI, not written by people. When a statement merges, an allowlisted open-weights model (pinned by SHA-256 in `models.toml`, run on CPU by a pinned llama.cpp) reads it once from a fixed prompt, with no system prompt, temperature 0 and top-k 1. The reading is published with the model, hashes, runtime and CPU. They're always shown as unverified. Anyone can reproduce one with `python3 -m tools.readings generate --model <name> <hash>`.
- **Featured and examples** are chosen by maintainers in `curation.toml`.
