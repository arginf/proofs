# tools

- Layout (2026-11-27): `layout.py` owns every path and module name. Statements live at `Theorems/<ab>/<hash>/Statement.lean`, attempts at `Theorems/<ab>/<hash>/attempts/<cd>/<attempt>/{Attempt.lean,attempt.toml}`, where `<ab>`/`<cd>` are the first two hex digits and hashes are 20 digits (`HASH_LEN`). `parse_path` accepts exactly those two shapes (fixed depth 4 and 7, shard checked); `check_scope`, `automerge.decide` and `check_all` all go through it. Never build a `Theorems/...` path or module by hand.
- Module paths are sharded (`Theorems.«ab».«hash».Statement`); namespaces are not (`Theorems.«hash»`, `Theorems.«hash».Attempt_<a>`). `safety.py` checks theorem imports with `layout.THEOREM_MODULE_RE`, which ties the shard to the hash.
- `migrate_layout.py` did the one-time move from 12-digit flat folders and wrote `migrations/2026-11-hash20.json` (old→new statements and attempts, plus each attempt's statement). Automerge's earned-credit parser and provenance read that map, so old merge titles and original merge dates still count. Keep the map; the site uses it for redirects.
- Shard fill is random: one directory passes GitHub's 3,000 entries at about 700k items per level, not 768k.
- `arginf.py path <hash> [<attempt>]` prints a folder; CONTRIBUTING and pr.yml use it instead of shell substrings.
- Run `python3 -m unittest discover -s tools/tests -t .` and `python3 tools/arginf.py check-all`.
- Merge queue (2026-11-27): automerge no longer merges. `automerge.enqueue` adds the `arginf:<kind>` label, then `enqueuePullRequest` with `expectedHeadOid` = the checked commit. pr.yml also runs on `merge_group` (check-all, then the full build); keep its job names (`scope`, `lean`) stable, they are the required checks.
- `ledger.py` owns "who merged what": entries come from labelled merged PRs (author, merge time and files from the API) plus automerge's pre-queue commit titles through the rename map. Never derive credit from commit authors or titles of new merges. main's `ledger` job uploads `ledger.json`; automerge reads the latest artifact (`ledger.read_ledger`), counts merges after that run with one search, and adds PRs still queued (`automerge.recent_count`). No ledger: last 24 h from the API and no earned credit (fail toward lower caps).
- Status comments (`announce.py`): one comment per PR, found by `MARKER` and authored by `github-actions[bot]` (never edit a user's copy). automerge posts "accepted, queued" after enqueueing (no badges: they can change while queued); main's ledger job (`ledger build --announce`) updates it after the merge with badges (first proof, shortest, earned credit) for entries new since the previous ledger and merged in the last 2 h. Comments quote nothing from the PR. Statement links use `announce.statement_url` (`https://arginf.com/theorems/<hash>`).
